# Third-party notices

Trend Watch is integrated into ReplyHalo as an isolated content-intelligence service.

The implementation is based in part on the user-provided TrendWatch bundle and draws concepts/code from these MIT-licensed projects:

## omkarcloud/instagram-scraper

Repository: https://github.com/omkarcloud/instagram-scraper

Used for the Instagram collection layer: public profiles, Reels, post details, similar accounts, discovery/trending surfaces, request retry/error taxonomy and proxy fallback concepts.

License: MIT.

## taoufik123-collab/claude-watch

Repository: https://github.com/taoufik123-collab/claude-watch

Used for the video-analysis layer: scene-change frame extraction, pacing metrics, dense first-10-second hook analysis and Whisper transcription.

License: MIT.

The ReplyHalo integration adds workspace isolation, authenticated internal API access, SaaS-oriented persistence and UI integration. Third-party copyright notices and license terms remain applicable to the portions derived from those projects.
